## 🚀 What I Learned in Expo Routing & Navigation

As part of my learning journey with **Expo (React Native)**, I completed a course by [Codevolution](https://www.youtube.com/playlist?list=PLC3y8-rFHvwgVmqbtQkPDxkvDf6w5_eGA) focused on advanced routing and navigation techniques. This course covered everything needed to build scalable and well-structured navigation systems in mobile apps.

### 🧭 Routing Fundamentals

- ✅ **File-based Routing** – Structuring screens with the file system
- 🔁 **Dynamic Routes** – Supporting parameterized navigation
- 📦 **Catch-all Segments** – Handling deep and optional paths
- 🚫 **Custom Not Found Pages** – Gracefully handling unmatched routes
- 🧩 **Layouts** – Sharing UI and logic across screens
- 🗂️ **Route Groups** – Organizing routes logically

### 🧑‍✈️ Navigation Techniques

- 🧭 **Navigation API** – Core methods for moving between screens
- 🧱 **Stack Navigation** – Push/pop-based screen transitions
- 🧭 **Tab Navigation** – Bottom tabs for sectioned navigation
- 📚 **Drawer Navigation** – Side menu for app-wide access
- 🪟 **Modals** – Overlay screens for secondary tasks
- 🛠️ **Platform-specific Code** – Tailoring behavior per OS
